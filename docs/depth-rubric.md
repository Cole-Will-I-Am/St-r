# Depth Rubric — The Quality Bar

Run every year against this before marking it **done**. The non-negotiables are
pass/fail. The depth dimensions are scored to push entries higher.

---

## Non-negotiables (any failure ⇒ not done)

- [ ] **Six events present** — exactly 3 U.S. + 3 world, each with a datable,
      sourced factual core.
- [ ] **Two narratives for each event** — the story *then* and the story *now*,
      explicitly distinguished.
- [ ] **All three lenses present** — Herald, Heretic, Cartographer each gave an
      opening interpretation and engaged in cross-examination.
- [ ] **Steelman observed** — no persona attacked a strawman; each restated its
      target fairly before pressing.
- [ ] **Intra-year connections mapped** — the six events are related to each
      other, not listed in isolation.
- [ ] **Carry-forward matches** — Section 0 picks up the prior year's handoff.
- [ ] **Handoff written** — specific threads passed to next year.
- [ ] **Thread to today** — a concrete line drawn to the present-day United States.
- [ ] **Disagreement preserved** — synthesis did not manufacture a fake verdict.
- [ ] **Fact / interpretation / speculation labeled** — and contested facts flagged.

---

## The textbook test

> If any paragraph could be lifted into a high-school textbook without objection,
> rewrite it.

Surface knowledge is the floor, not the deliverable.

---

## Depth dimensions (score each 1–5; aim for 4+)

| Dimension | 1 (surface) | 5 (deep) |
|---|---|---|
| **Narrative pressure** | Repeats the received story | Dissects how the story was built and what it hides |
| **Then vs. now** | Mentions both exist | Mines the *gap* between them for meaning |
| **Causal layering** | Single cause / great man | Event, conjuncture, and structure interwoven |
| **Connection** | Events listed separately | Hidden shared drivers exposed; threads traced |
| **Through-line to today** | Vague "shaped America" | Names a specific present-day inheritance |
| **Honesty** | Confident where evidence is thin | Marks uncertainty; preserves real disagreement |
| **Voice** | Encyclopedic | Seminar-brilliant; unsettling but earned |

---

## The single test (from the methodology)

> **Does this entry change how a thoughtful reader understands the present?**

If it only informs them about the past, keep going.

---

## Common failure patterns to catch

- **Both-sidesing into mush** — three lenses that all say the same cautious thing.
  The personas should genuinely clash.
- **Counter-myth** — the Heretic replaced one tidy story with an equally tidy
  inverse.
- **Determinism creep** — the Cartographer erased all contingency.
- **Anachronism** — judging actors only by today's categories.
- **Connection inflation** — claiming links the evidence doesn't support.
- **Presentist flattery / cynicism** — making the past either a villain or a
  golden age to score a present-day point.
